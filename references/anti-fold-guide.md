# 微信朋友圈防折叠与多号分发指南

> 方法论致谢：借鉴 GitHub 开源项目 `mengke-wang/wechat-anti-fold` 的四层改写框架，并结合微信客户端实际折叠规则整理。

## 一、微信朋友圈为什么会被折叠？

1. **长文自动折叠（单条维度）**：
   - 当一条朋友圈超过约 **6 行** 或约 **100 字** 时，微信信息流会将其折叠，只露出前几行并显示「全文」。
   - **解法**：前 **25–35 个字**（第 1 段）必须是一句完整的强钩子，让用户不用点「全文」就产生好奇。
2. **相似内容折叠（多号/高频维度）**：
   - 两个微信号（或同一团队矩阵号）发高度相似的文案，或者短时间内反复发同结构文案，微信算法会将后发的折叠成「一条相似内容」，几乎零曝光。
   - **解法**：发第二/第三个号时，必须做**四层差异化改写**，使字面 2-gram / 3-gram 重合度降到 **35% 以下**。

## 二、四层防折叠改写法则

当需要把同一条核心文案分发到第 2、第 3 个微信号，或同主题隔几天再发时，按以下 4 层依次改写：

1. **换开头（决定 80% 判重权重）**：
   - 原版用「数据/结论开头」→ 改写版换成「好友聊天/场景提问开头」。
   - 例：
     - A 号：`很多老板问我，为什么公司装了一堆 AI 工具反而更乱？`
     - B 号：`刚跟一个开工厂的哥们喝茶，他吐槽花几万块买了一堆软件，员工还是天天加班。`
2. **换句式与顺序（结构重组）**：
   - 原版是「结论 → 原因 1/2/3」→ 改写版换成「反问 → 故事案例 → 一句话总结」。
3. **换词汇与具象动词（同义与口语替换）**：
   - 避免保留完全相同的四字成语、数字表达或专有短语连续出现。
   - 把抽象名词换成具体动作（如「提升效率」→「原本弄一下午，现在 10 分钟出初稿」）。
4. **换结尾与互动钩子**：
   - A 号用「观点金句收尾」→ B 号换成「征集评论或自嘲收尾」。

## 三、用脚本快速校验防折叠效果

使用内置脚本对比两个版本的重合度（建议 2-gram 重合率 `< 0.35`，首行重合率 `< 0.30`）：

```bash
python3 scripts/moments_check.py --file post_a.txt --compare post_b.txt
```
